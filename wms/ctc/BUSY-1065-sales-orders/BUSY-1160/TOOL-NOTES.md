# BUSY-1160 tool notes

Bugs, blind spots and traps found in the scripts themselves, not in the system under test. A failing
case is not a defect until the tool has been ruled out.

## Carried from other plans, still true here

* **`cin7-watermark.sh` defaults to `--poller item`.** Every sales order call needs `--poller so`.
  The wrong flag rewinds the item master feed.
* **An empty reading from `tail-logs.sh` or `check-status.sh` is not evidence of no traffic.** Under
  light load the work goes through a shared queue and a direct Lambda invoke that neither tool
  watches. From BUSY-1260.
* **`REPORT.*Task timed out` returns zero on this runtime.** The real marker is `Status: timeout`. A
  session trusting the old pattern concluded there were no timeouts when there were 180 in 7 days.
  From BUSY-1260.
* **Reading a DLQ with `--visibility-timeout 0` is safe for the message but still increments
  `ApproximateReceiveCount`.** Snapshot the counts on the first call or treat them as an upper bound.
* **A lambda's log group can be a year stale against its own `LastModified`.**
  `staging-orders-v2-list-orders` last logged in September 2025 against a 2026-09-03 deploy. Check
  log recency before trusting silence.
* **`survey-cin7-orders.sh`'s `taxStatus` counter and its stage cross-tabs are additive changes that
  have not been reviewed by a second person.**

## Confluence publishing

**A bold span that crosses an inline-code run does not survive the markdown round-trip.** Confluence's
ADF conversion closes the `**` before the backticked run instead of after the intended word. The
wording is untouched, only the marker moves, but it shows up as a real diff on every verification and
wastes a check. Keep bold spans on one side of a backticked run. Found on the BUSY-1160 page,
2026-09-08, version 7, and fixed in the source so the next push reconciles.

Table separator rows normalise from `|---|---|` to `| --- | --- |` and some rows gain a trailing
blank cell. That is the platform serialising markdown and is not a content change. Expect it on every
push and do not chase it.
